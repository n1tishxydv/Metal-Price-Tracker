# Metal Price Tracker

A C++-based metal price tracking and analysis project for monitoring precious metal prices such as Gold and Silver.

## Project Structure

- `backend/` - C++ backend/server implementation
- `frontend/` - Frontend interface
- `data/` - Project datasets and price data
- `build_msvc.cmd` - Build script
- `run_server.cmd` - Server startup script

## Tech Stack

- C++
- HTML / CSS / JavaScript
- MSVC
- JSON / Data Files

## Features

- Metal price tracking
- Gold and Silver price data management
- Backend API/server
- Frontend dashboard
- Local data processing
